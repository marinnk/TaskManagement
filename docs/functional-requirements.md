# 機能要件：Trello風タスク管理アプリ

[← 要件定義書に戻る](要件定義書.md)

## 機能一覧

| No | 機能 | 内容 |
|---|---|---|
| 1 | ボード表示 | ボードを開くと、複数のリストが横並びで表示される |
| 2 | リスト表示 | 「未着手」「作業中」「完了」の3つのリストを表示する |
| 3 | カード追加 | リストの「カード追加」ボタンからポップアップを開き、タイトル（必須）・説明・期限を入力してカードを追加できる |
| 4 | カード編集 | カードをダブルクリックするとポップアップが開き、タイトル・説明・期限を編集して保存できる |
| 5 | カード移動 | カードをドラッグ&ドロップして別のリストに移動できる |
| 6 | カード削除 | 不要になったカードを削除できる |
| 7 | データ保持 | 追加・編集・移動したカードの状態はページを再読み込みしても保持される（DB保存） |

※ 本バージョンは最小限の機能に絞る。担当者・ラベル、リスト名の追加・編集・削除、複数ボードの管理などは対象外とし、余力があれば次バージョン以降で検討する。

## ユースケース

アクターは「利用者」の1名のみ（ログイン機能がないため区別しない）。

### UC01：ボードを開く
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | アプリが起動している |
| 基本フロー | 1. 利用者がボード画面にアクセスする<br>2. システムは登録済みのリストとカードを表示順に並べて表示する |
| 事後条件 | 現在のボードの状態が画面に表示されている |
| 例外フロー | データが1件もない場合、空のリストのみ表示する |

### UC02：カードを追加する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | ボード画面を開いている |
| 基本フロー | 1. 利用者がリストの「カード追加」ボタンを押す<br>2. ポップアップが表示され、タイトル（必須）・説明・期限を入力する<br>3. 追加操作を行う<br>4. システムはカードをDBに保存し、該当リストの末尾に表示する |
| 事後条件 | 新しいカードがリストに追加され、再読み込みしても保持されている |
| 例外フロー | タイトルが未入力の場合は追加を行わない。説明・期限は未入力でもよい |

### UC03：カードを編集する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | 編集対象のカードが存在する |
| 基本フロー | 1. 利用者がカードをダブルクリックする<br>2. ポップアップが表示され、既存のタイトル・説明・期限が入力済みで表示される<br>3. 内容を変更し、保存操作を行う<br>4. システムはカードの内容をDBに反映する |
| 事後条件 | カードの内容が更新され、再読み込みしても保持されている |
| 例外フロー | タイトルを空にした場合は保存を行わない。キャンセル操作をした場合は変更を破棄する |

### UC04：カードを別のリストに移動する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | 移動対象のカードが存在する |
| 基本フロー | 1. 利用者がカードをドラッグする<br>2. 移動先のリスト上でドロップする<br>3. システムは対象カードの所属リストと表示順を更新する |
| 事後条件 | カードが移動先リストに表示され、再読み込みしても保持されている |
| 例外フロー | リスト外にドロップした場合は移動前の位置に戻す |

### UC05：カードを削除する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | 削除対象のカードが存在する |
| 基本フロー | 1. 利用者がカードの削除操作を行う<br>2. システムは対象カードをDBから削除する |
| 事後条件 | カードが画面上・DB上から消え、再読み込みしても復活しない |
| 例外フロー | なし（削除確認ダイアログは本バージョンでは設けない） |
