# 機能要件：Trello風タスク管理アプリ

[← 要件定義書に戻る](要件定義書.md)

## 機能一覧

1. ボード表示  
   ボードを開くと、複数のリストが横並びで表示される
2. リスト表示  
   「未着手」「作業中」「完了」の3つのリストを表示する。各リスト名の横に、そのリストに含まれるカードの枚数を表示する
3. カード追加  
   リストの「カード追加」ボタンからポップアップを開き、タイトル（必須）・説明・期限を入力してカードを追加できる。期限を入力した場合、そのリスト内で期限が早い順になる位置に自動的に挿入される
4. カード編集  
   カードをダブルクリックするとポップアップが開き、タイトル・説明・期限を編集して保存できる。期限を設定・変更した場合も、リスト内で期限が早い順になる位置に自動的に並び替えられる
5. カード移動・並び替え  
   カードをドラッグ&ドロップして別のリストに移動できる。同一リスト内でもドラッグ&ドロップでカードの順番を入れ替えられる
6. カード削除  
   不要になったカードを、確認ダイアログでの確認後に削除できる
7. カードの期限順並べ替え  
   各リストの「期限順」ボタンで、そのリスト内のカードを期限が早い順（期限未設定のカードは末尾）に並べ替えられる
8. データ保持  
   追加・編集・移動したカードの状態はページを再読み込みしても保持される（DB保存）

※ 本バージョンは最小限の機能に絞る。担当者・ラベル、リスト名の追加・編集・削除、複数ボードの管理などは対象外とし、余力があれば次バージョン以降で検討する。

## ユースケース

アクターは「利用者」の1名のみ（ログイン機能がないため区別しない）。

### UC01：ボードを開く

**アクター**  
利用者

**事前条件**  
アプリが起動している

**基本フロー**  
1. 利用者がボード画面にアクセスする
2. システムは登録済みのリストとカードを表示順に並べて表示する

**事後条件**  
現在のボードの状態が画面に表示されている

**例外フロー**  
データが1件もない場合、空のリストのみ表示する

### UC02：カードを追加する

**アクター**  
利用者

**事前条件**  
ボード画面を開いている

**基本フロー**  
1. 利用者がリストの「カード追加」ボタンを押す
2. ポップアップが表示され、タイトル（必須）・説明・期限を入力する
3. 追加操作を行う
4. システムはカードをDBに保存する。期限が設定されている場合は該当リスト内で期限が早い順になる位置に、期限が未設定の場合は該当リストの末尾に表示する

**事後条件**  
新しいカードがリストに追加され、再読み込みしても保持されている

**例外フロー**  
タイトルが未入力の場合は追加を行わない。説明・期限は未入力でもよい

### UC03：カードを編集する

**アクター**  
利用者

**事前条件**  
編集対象のカードが存在する

**基本フロー**  
1. 利用者がカードをダブルクリックする
2. ポップアップが表示され、既存のタイトル・説明・期限が入力済みで表示される
3. 内容を変更し、保存操作を行う
4. システムはカードの内容をDBに反映する。期限を設定・変更した場合は、該当リスト内で期限が早い順になる位置にカードを並び替える

**事後条件**  
カードの内容が更新され、再読み込みしても保持されている

**例外フロー**  
タイトルを空にした場合は保存を行わない。キャンセル操作をした場合は変更を破棄する

### UC04：カードを移動・並び替える

**アクター**  
利用者

**事前条件**  
対象のカードが存在する

**基本フロー**  
1. 利用者がカードをドラッグする
2. 移動先リストの任意の位置、または同一リスト内の任意の位置でドロップする
3. システムは対象カードの所属リストと表示順を更新する

**事後条件**  
カードが新しい位置（別リストまたは同一リスト内の別の順番）に表示され、再読み込みしても保持されている

**例外フロー**  
リスト外にドロップした場合は移動前の位置に戻す

### UC05：カードを削除する

**アクター**  
利用者

**事前条件**  
削除対象のカードが存在する

**基本フロー**  
1. 利用者がカードの削除操作を行う
2. 確認ダイアログが表示される
3. 利用者が削除を確定する
4. システムは対象カードをDBから削除する

**事後条件**  
カードが画面上・DB上から消え、再読み込みしても復活しない

**例外フロー**  
確認ダイアログでキャンセルした場合は削除しない
