## 画面一覧

| 画面ID | 画面名 | 概要 | 遷移先 |
|---|---|---|---|
| S01 | ボード画面 | リストとカードを表示・操作するメイン画面（本アプリの唯一の画面） | なし（単一画面構成のため画面遷移はなし） |

## 画面イメージ（ワイヤーフレーム）

```
+--------------------------------------------------------------+
| ボード名                                                       |
+--------------------------------------------------------------+
|  未着手 (2)     |  作業中 (2)     |  完了 (1)       |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードA   |  |  | カードC   |  |  | カードE   |  |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードB   |  |  | カードD   |  |  +-----------+  |
|  +-----------+  |  +-----------+  |                 |
|  [+ カード追加]  |  [+ カード追加]  |  [+ カード追加]  |
+--------------------------------------------------------------+
```

### カード追加ポップアップ（ワイヤーフレーム）

```
        +-----------------------------+
        | カードを追加                 |
        |                             |
        | タイトル                     |
        | [___________________]       |
        |                             |
        | 説明                        |
        | [___________________]       |
        | [___________________]       |
        |                             |
        | 期限                        |
        | [___________________]       |
        |                             |
        |            [キャンセル][追加] |
        +-----------------------------+
```

- 各リスト名の横に、そのリストに含まれるカードの枚数をバッジ表示する
- 各リストの下部に「+ カード追加」ボタンを配置する
- ボタン押下でポップアップ（モーダル）を表示し、タイトル（必須）・説明・期限を入力してカードを追加する
- カードをダブルクリックすると、同じポップアップが見出し「カードを編集」・ボタン「保存」の編集モードで開き、既存のタイトル・説明・期限を編集して保存できる
- カードはドラッグ&ドロップでリスト間を移動できる
- カード上に削除ボタン（×等）を配置する
- 期限を設定したカードには、カード上に期限を表示する
