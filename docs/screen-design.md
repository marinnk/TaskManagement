## 画面一覧

| 画面ID | 画面名 | 概要 | 遷移先 |
|---|---|---|---|
| S01 | ボード画面 | リストとカードを表示・操作するメイン画面（本アプリの唯一の画面） | なし（単一画面構成のため画面遷移はなし） |

## 画面イメージ（ワイヤーフレーム）

```
+--------------------------------------------------------------+
| ボード名                                                       |
+--------------------------------------------------------------+
|  未着手 (2)     |  作業中 (2)     |  完了 (1)       |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードA   |  |  | カードC   |  |  | カードE   |  |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードB   |  |  | カードD   |  |  +-----------+  |
|  +-----------+  |  +-----------+  |                 |
|  [+ カード追加]  |  [+ カード追加]  |  [+ カード追加]  |
+--------------------------------------------------------------+
```

### カード追加ポップアップ（ワイヤーフレーム）

```
        +-----------------------------+
        | カードを追加                 |
        |                             |
        | タイトル                     |
        | [___________________]       |
        |                             |
        | 説明                        |
        | [___________________]       |
        | [___________________]       |
        |                             |
        | 期限                        |
        | [___________________]       |
        |                             |
        |            [キャンセル][追加] |
        +-----------------------------+
```

- 各リスト名の横に、そのリストに含まれるカードの枚数をバッジ表示する
- 各リスト名の横に「期限順」ボタンを配置し、押下するとそのリスト内のカードを期限が早い順（期限未設定のカードは末尾）に並べ替える
- 各リストの下部に「+ カード追加」ボタンを配置する
- ボタン押下でポップアップ（モーダル）を表示し、タイトル（必須）・説明・期限を入力してカードを追加する
- カードをダブルクリックすると、同じポップアップが見出し「カードを編集」・ボタン「保存」の編集モードで開き、既存のタイトル・説明・期限を編集して保存できる
- カードはドラッグ&ドロップでリスト間を移動できる。同一リスト内でもドラッグ&ドロップで順番を入れ替えられる
- カード上に削除ボタン（×等）を配置する。押下すると確認ダイアログ（モーダル）が表示され、確定操作で削除される
- 期限を設定したカードには、カード上に期限を表示する
- カードを追加・編集して期限を設定すると、そのリスト内で期限が早い順になる位置に自動的に並び替えられる（期限未設定のカードの並び順はそのまま維持される）
