## 改訂履歴

| バージョン | 日付 | 変更内容 |
|---|---|---|
| 1.0 | 2026-07-22 | 初版作成（最小構成） |
| 1.1 | 2026-07-24 | 画面要件（ワイヤーフレーム）、非機能要件、用語集を追加。スケジュールを実態にあわせて簡略化 |

## 1. 概要・目的
- 本アプリは、Trelloのようなかんばん方式のタスク管理Webアプリケーションである
- 目的：AIを活用したWebアプリ開発の習得（Java / Spring Bootでの開発をAIの支援を受けながら学ぶ）

## 2. 対象ユーザー
- 個人でタスクを管理したい利用者（複数人での共同編集やログイン機能は本バージョンでは対象外）

## 3. 機能要件

| No | 機能 | 内容 |
|---|---|---|
| 1 | ボード表示 | ボードを開くと、複数のリストが横並びで表示される |
| 2 | リスト表示 | 「未着手」「作業中」「完了」の3つのリストを表示する |
| 3 | カード追加 | リストに新しいタスク（カード）を追加できる |
| 4 | カード移動 | カードをドラッグ&ドロップして別のリストに移動できる |
| 5 | カード削除 | 不要になったカードを削除できる |
| 6 | データ保持 | 追加・移動したカードの状態はページを再読み込みしても保持される（DB保存） |

※ 本バージョンは最小限の機能に絞る。カードの詳細編集（タイトル変更、説明文、期限、担当者、ラベル等）、リスト名の追加・編集・削除、複数ボードの管理などは対象外とし、余力があれば次バージョン以降で検討する。

## 4. ユースケース

アクターは「利用者」の1名のみ（ログイン機能がないため区別しない）。

### UC01：ボードを開く
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | アプリが起動している |
| 基本フロー | 1. 利用者がボード画面にアクセスする<br>2. システムは登録済みのリストとカードを表示順に並べて表示する |
| 事後条件 | 現在のボードの状態が画面に表示されている |
| 例外フロー | データが1件もない場合、空のリストのみ表示する |

### UC02：カードを追加する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | ボード画面を開いている |
| 基本フロー | 1. 利用者がリストの「カード追加」欄にタイトルを入力する<br>2. 追加操作を行う<br>3. システムはカードをDBに保存し、該当リストの末尾に表示する |
| 事後条件 | 新しいカードがリストに追加され、再読み込みしても保持されている |
| 例外フロー | タイトルが未入力の場合は追加を行わない |

### UC03：カードを別のリストに移動する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | 移動対象のカードが存在する |
| 基本フロー | 1. 利用者がカードをドラッグする<br>2. 移動先のリスト上でドロップする<br>3. システムは対象カードの所属リストと表示順を更新する |
| 事後条件 | カードが移動先リストに表示され、再読み込みしても保持されている |
| 例外フロー | リスト外にドロップした場合は移動前の位置に戻す |

### UC04：カードを削除する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 事前条件 | 削除対象のカードが存在する |
| 基本フロー | 1. 利用者がカードの削除操作を行う<br>2. システムは対象カードをDBから削除する |
| 事後条件 | カードが画面上・DB上から消え、再読み込みしても復活しない |
| 例外フロー | なし（削除確認ダイアログは本バージョンでは設けない） |

## 5. 非機能要件
- 開発言語・フレームワーク：Java / Spring Boot
- データベース：H2（学習用途に適した組み込みDB。追加インストール不要）
- フロントエンド：Thymeleaf（サーバー側でHTML生成）+ JavaScript（ドラッグ&ドロップ操作用）
- 動作環境：一般的なモダンブラウザ（Chrome等）で動作すること
- 性能：個人利用を前提とし、同時アクセスや大量データは考慮しない（カード数は数十〜数百件程度を想定）
- セキュリティ：ログイン機能を持たないため、外部には公開せずローカル環境／学習用途での利用に限定する
- データ永続化：H2をファイルモードで使用し、アプリ再起動後もデータを保持する（自動バックアップは対象外）
- 可用性：個人学習用のため稼働率・障害対応の要件は定めない

## 6. 画面一覧

| 画面ID | 画面名 | 概要 | 遷移先 |
|---|---|---|---|
| S01 | ボード画面 | リストとカードを表示・操作するメイン画面（本アプリの唯一の画面） | なし（単一画面構成のため画面遷移はなし） |

### 画面イメージ（ワイヤーフレーム）

```
+--------------------------------------------------------------+
| ボード名                                                       |
+--------------------------------------------------------------+
|  未着手         |  作業中         |  完了           |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードA   |  |  | カードC   |  |  | カードE   |  |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードB   |  |  | カードD   |  |  +-----------+  |
|  +-----------+  |  +-----------+  |                 |
|  [+ カード追加]  |  [+ カード追加]  |  [+ カード追加]  |
+--------------------------------------------------------------+
```

- 各リストの下部に「カード追加」の入力欄・ボタンを配置する
- カードはドラッグ&ドロップでリスト間を移動できる
- カード上に削除ボタン（×等）を配置する

## 7. データ要件

| エンティティ | 主な項目 |
|---|---|
| Board | id, ボード名 |
| List | id, リスト名, 所属Board, 表示順 |
| Card | id, タイトル, 所属List, 表示順 |

### テーブル定義

#### board

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | ボードID |
| name | VARCHAR(100) | NOT NULL | ボード名 |

#### list

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | リストID |
| name | VARCHAR(50) | NOT NULL | リスト名（「未着手」「作業中」「完了」） |
| board_id | BIGINT | FK → board.id, NOT NULL | 所属ボードID |
| display_order | INT | NOT NULL | ボード内での表示順（0始まり） |

#### card

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | カードID |
| title | VARCHAR(200) | NOT NULL | カードのタイトル |
| list_id | BIGINT | FK → list.id, NOT NULL | 所属リストID |
| display_order | INT | NOT NULL | リスト内での表示順（0始まり） |

### ER図（概略）

```
board (1) --- (多) list (1) --- (多) card
```

- 1つのboardは複数のlistを持つ
- 1つのlistは複数のcardを持つ
- list削除・card削除は本バージョンの機能要件に無いため、カスケード削除の仕様は次バージョンで検討する

## 8. スケジュール・体制
- 開発体制：個人開発
- スケジュール：学習目的のため厳密な期限は設けない（2026-08-01 頃を目安とする）

## 9. 用語集

| 用語 | 説明 |
|---|---|
| ボード | タスク管理全体の単位。リストをまとめる入れ物 |
| リスト | ボード内でカードを分類する列（本バージョンでは「未着手」「作業中」「完了」の3つ固定） |
| カード | 個々のタスクを表す単位。リストに所属する |
| ドラッグ&ドロップ | マウス操作でカードをつかんで別のリストへ移動する操作 |
| ユースケース | 利用者がシステムを使って目的を達成するまでの一連の操作・処理の流れを記述したもの |
