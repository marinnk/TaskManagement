# 画面設計：Trello風タスク管理アプリ

[← 要件定義書に戻る](要件定義書.md)

## 画面一覧

| 画面ID | 画面名 | 概要 | 遷移先 |
|---|---|---|---|
| S01 | ボード画面 | リストとカードを表示・操作するメイン画面（本アプリの唯一の画面） | なし（単一画面構成のため画面遷移はなし） |

## 画面イメージ（ワイヤーフレーム）

```
+--------------------------------------------------------------+
| ボード名                                                       |
+--------------------------------------------------------------+
|  未着手         |  作業中         |  完了           |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードA   |  |  | カードC   |  |  | カードE   |  |
|  +-----------+  |  +-----------+  |  +-----------+  |
|  | カードB   |  |  | カードD   |  |  +-----------+  |
|  +-----------+  |  +-----------+  |                 |
|  [+ カード追加]  |  [+ カード追加]  |  [+ カード追加]  |
+--------------------------------------------------------------+
```

- 各リストの下部に「カード追加」の入力欄・ボタンを配置する
- カードはドラッグ&ドロップでリスト間を移動できる
- カード上に削除ボタン（×等）を配置する
