## 1. 概要・目的
- 本アプリは、Trelloのようなかんばん方式のタスク管理Webアプリケーションである
- 目的：AIを活用したWebアプリ開発の習得（Java / Spring Bootでの開発をAIの支援を受けながら学ぶ）

## 2. 対象ユーザー
- 個人でタスクを管理したい利用者（複数人での共同編集やログイン機能は本バージョンでは対象外）

## 4. スケジュール・体制
- 開発体制：個人開発
- スケジュール：学習目的のため厳密な期限は設けない（2026-08-01 頃を目安とする）

## 5. 用語集

| 用語 | 説明 |
|---|---|
| ボード | タスク管理全体の単位。リストをまとめる入れ物 |
| リスト | ボード内でカードを分類する列（本バージョンでは「未着手」「作業中」「完了」の3つ固定） |
| カード | 個々のタスクを表す単位。リストに所属する |
| ドラッグ&ドロップ | マウス操作でカードをつかんで別のリストへ移動する操作 |
| ユースケース | 利用者がシステムを使って目的を達成するまでの一連の操作・処理の流れを記述したもの |
