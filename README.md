# TaskManagement

Trello風のかんばん方式タスク管理Webアプリケーション。

## 概要

個人でタスクを管理したい利用者向けに、ボード・リスト・カードを使ってタスクを視覚的に管理できるアプリを目指します。AIを活用したWebアプリ開発の学習を目的としたスクール課題です。

詳細な仕様は [要件定義書](docs/requirements.md) を参照してください。

## 使用技術

- Java / Spring Boot
- Thymeleaf
- H2 Database
- JavaScript（ドラッグ&ドロップ操作）
